# ToolkitAPI — Python Examples

[![PyPI](https://img.shields.io/pypi/v/toolkitapi)](https://pypi.org/project/toolkitapi/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Runnable Python examples for every [ToolkitAPI.io](https://toolkitapi.io) endpoint, using the official [`toolkitapi`](https://pypi.org/project/toolkitapi/) SDK.

## Prerequisites

- Python **3.9+**
- pip

## Setup

```bash
pip install toolkitapi
export TOOLKITAPI_KEY=tk_live_...
```

## Running an example

Each file is a self-contained script. Run any one directly:

```bash
python dns/lookup.py
python email/validate_email.py
python auth/jwt_generate.py
```
